## What I'm building now

- 🕷️ **[minicrawl](https://github.com/fairoz-539/minicrawl)**: a self-hosted, Firecrawl-compatible scraping API. Give it a website, PDF, Office file or image and get back clean markdown or JSON for your LLM. Starts with one `docker compose up`. Comes with a Python client and an MCP server (both listed below). (Node.js, Docker)

## npm packages

- 🎨 **[SlideCanvas](https://github.com/fairoz-539/SlideCanvas)**: view and edit .pptx files right in the browser, with pixel-perfect rendering, an Office-style toolbar and AI rewriting. (TypeScript, Fabric.js, Gemini) · [`npm i slidecanvas`](https://www.npmjs.com/package/slidecanvas)
- 📊 **[canva-pptx](https://github.com/fairoz-539/canva-pptx)**: build branded PowerPoint decks from code using reusable components and themes, instead of placing every box by hand. · [`npm i canva-pptx`](https://www.npmjs.com/package/canva-pptx)
- 🚨 **[env-police](https://github.com/fairoz-539/env-police)**: a zero-config CLI that fails your CI when your code uses an environment variable that's missing from `.env`. · [`npx env-police`](https://www.npmjs.com/package/env-police)
- 🔌 **[minicrawl-mcp](https://github.com/fairoz-539/minicrawl/tree/main/integrations/mcp)**: an MCP server that gives Claude Desktop, Cursor and other AI agents self-hosted scraping, crawling and search through minicrawl. · [`npx minicrawl-mcp`](https://www.npmjs.com/package/minicrawl-mcp)
